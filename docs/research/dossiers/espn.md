# ESPN site/core API

- **id:** `espn`
- **domain:** sports scoreboard, teams, news, odds, summaries
- **base:** `https://site.api.espn.com/apis/site/v2/sports`
- **auth:** none
- **freshness:** 15s live, 5min static
- **limits:** undocumented, CDN
- **evidence fixtures:** espn.json (84627 B), espn_teams.json (148848 B), espn_summary.json (449689 B), espn_odds.json (15531 B) (698695 B)

| method | path | status | note |
| --- | --- | --- | --- |
| GET | `/{sport}/{league}/scoreboard` | 200 | live scoreboard + embedded odds/links |
| GET | `/{sport}/{league}/teams` | 200 | team directory with logos/colors |
| GET | `/{sport}/{league}/summary?event=` | 200 | boxscore, plays, leaders, injuries, venue, officials, broadcasts |
