# AniList

- **id:** `anilist`
- **domain:** anime, manga
- **base:** `https://graphql.anilist.co`
- **auth:** none
- **freshness:** realtime, 60s cache
- **limits:** ~90 req/min degraded bucket; HTTP 429 + Retry-After
